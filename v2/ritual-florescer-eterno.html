Edição de presente

Rosas Brancas · Chá Branco · Lichia

Nem todo banho é rotina. Alguns são data marcada. O Florescer Eterno nasceu para esses: rosas brancas, chá branco e lichia numa mesma alquimia, em quatro peças pensadas para serem dadas de presente. É a linha em que a Cerrô se permite o gesto, não só o cuidado.

Para quem: quem vai presentear e quer entregar algo que já chega pronto, sem precisar montar nada.

Como levar

O ritual
completo

As quatro peças chegam juntas, na caixa, prontas para entregar. Não é preciso montar nem embrulhar nada.

Cada peça é feita à mão em pequenos lotes, então a produção leva alguns dias antes do envio. Se for para uma data marcada, peça com antecedência.

Como usar

A ordem
do banho

Comece pelo esfoliante

Sobre a pele úmida, em movimentos circulares, dos pés para cima. Os cristais de quartzo tiram a aspereza e preparam a pele para o resto.

Limpe com o sabonete

O Coração Entrelaçado para o corpo todo, o Mil Flores para as áreas mais sensíveis. Deixe a espuma agir um minuto antes de enxaguar.

Feche com a geleia

Uma colher espalhada com a pele ainda molhada. É ela que deixa o brilho fino do pó de pérola e o aroma que fica depois do banho.
